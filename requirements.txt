# ---- Core deep learning ----
# 平台差异提醒（Linux 训练服务器 A100/H100 vs. Windows 本地开发机）：
#   Linux：PyPI 上的默认 Linux torch wheel 自带 CUDA（通过 nvidia-*-cuXX 依赖包自动拉取），
#     直接 `pip install -r requirements.txt` 即可装到 GPU 版本，无需额外指定索引源。
#   Windows：PyPI 上的默认 Windows torch wheel 是 CPU-only 版本，必须先单独装好 GPU 版，
#     再跑本文件，顺序如下（先装 torch 全家桶，再装其余依赖，避免版本约束被 CPU 版"满足"掉）：
#       pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu128
#       pip install -r requirements.txt
#     若已经先跑过本文件导致装成了 CPU 版，需要先 `pip uninstall torch torchvision torchaudio -y`
#     再执行上面两条命令（不加 -U/卸载重装的话，无版本号的 `pip install torch ...` 会因为
#     "已满足约束"而跳过安装，不会真的换成 GPU 版）。
#     具体该用哪个 cuXXX 索引（cu124/cu128/...）以 https://pytorch.org/get-started/locally/
#     页面为准，随显卡型号和驱动版本变化，此处不写死具体值。
# 上限很重要：不设上限时 `pip install -r` 会拉到最新 torch（如 2.14.0+cu130，按 CUDA 13.0 编译），
# 在只支持 CUDA 12.2 的旧驱动节点上会报 "NVIDIA driver on your system is too old"。
# 集群 GPU 节点驱动为 CUDA 12.2，请用 cu121 wheel 安装：
#   pip install torch==2.5.1 torchvision==0.20.1 torchaudio==2.5.1 --index-url https://download.pytorch.org/whl/cu121
